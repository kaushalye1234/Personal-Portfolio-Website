The context

The problem worth solving.

Students need a way to find relevant lost-item reports without manually scanning every entry. Search connects a description of a missing item with potentially useful reports.

My contribution

The lost-item search feature and its place in the report discovery workflow.

Team application

The broader application includes item reports, filtering, user messaging, and resolved-report states.

System context

A React frontend communicates with an Express API backed by MongoDB. Authentication and administration belong to the wider team scope.

A technical decision

Search belongs close to the report list so students can refine what they see while keeping report details accessible. The case study separates my search work from the rest of the team application.

Testing & evidence

The source is available for inspection. This portfolio does not claim a fresh automated search test run or a verified live frontend deployment.

What I would verify next

Useful search checks include matching and non-matching queries, clearing a query, empty results, loading, and API failures.
